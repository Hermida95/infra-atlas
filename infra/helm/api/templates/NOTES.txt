Infra Atlas API: {{ .Values.replicaCount }} replicas behind the Service {{ include "api.fullname" . }} ({{ .Values.service.type }}, port {{ .Values.service.port }}).

A ClusterIP Service is only reachable inside the cluster. To call it from your machine:

  kubectl --namespace {{ .Release.Namespace }} port-forward svc/{{ include "api.fullname" . }} 8000:{{ .Values.service.port }}

Then, in another terminal:

  curl http://localhost:8000/health    # liveness: the process answers
  curl http://localhost:8000/ready     # readiness: graph, index and model loaded
  curl "http://localhost:8000/search?q=where+do+I+keep+database+passwords&k=3"

Watch the pods start (startupProbe), then become Ready (readiness on {{ .Values.probes.readiness.path }}):

  kubectl --namespace {{ .Release.Namespace }} get pods -l app.kubernetes.io/instance={{ .Release.Name }} -w
