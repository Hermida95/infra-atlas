The kubelet is the only component that can start a container, and it takes instructions from
exactly one place: the API server's list of Pods whose `spec.nodeName` is this node. It does not
take orders from the scheduler, the controller-manager or kubectl -- all of those write objects,
and the kubelet reads them. That is why a Pod can be `Running` according to its Deployment and
nowhere to be found on the node: the kubelet is the thing that closes the gap, and if it is
unhealthy, nothing does.

**It is responsible for the node, not for the cluster.** It reports node conditions and
capacity, enforces its own eviction thresholds, runs probes locally, and restarts containers
according to `restartPolicy` -- all without asking anyone. This local autonomy is why running
Pods survive a control plane outage: the kubelet already knows what should be running and keeps
it running, re-pulling images and restarting crashed containers on its own.

**Most "the Pod will not start" problems live here**, and each has a distinct phase.
`ImagePullBackOff` is the CRI failing to pull -- wrong name, missing imagePullSecret, rate
limit. `ContainerCreating` that never ends is usually a volume: a CSI attach that never
completed, a missing Secret or ConfigMap referenced by a projected volume.
`CrashLoopBackOff` means the container started and exited, so the problem is the application and
`kubectl logs --previous` has it. `Running` but not `Ready` is a readiness probe.
`kubectl describe pod` plus the kubelet's own journal on that node distinguishes all four in
under a minute.

**Its own security surface is significant.** The kubelet API on port 10250 can list Pods and
exec into them; left unauthenticated, it is a complete bypass of the API server's RBAC. The
hardening is fixed: `--anonymous-auth=false`, webhook authorisation so the API server decides,
the read-only port disabled, and the NodeRestriction admission plugin on so a compromised
kubelet cannot edit other nodes or other nodes' Pods. On managed clusters this is done for you;
on anything self-built it is the first thing to check.
