A Deployment is the standard way to run a stateless application, and it is a controller of a
controller: it creates a ReplicaSet for each distinct Pod template and manages the replica counts
across them. Understanding that indirection is what makes rollouts predictable --
`kubectl get rs` during a deploy shows the old ReplicaSet draining and the new one filling, which
is the deploy, visible.

**Any change to the Pod template starts a rollout.** The controller hashes the template into
`pod-template-hash` and, if no ReplicaSet has that hash, creates one. This is why
`kubectl rollout restart` works by adding a timestamp annotation to the template: nothing
functional changes, but the hash does, so every Pod is replaced. It is also why editing something
outside the template -- `replicas`, the strategy -- does not cause a rollout.

**Rollback is cheap because the old ReplicaSet is still there** at zero replicas.
`kubectl rollout undo` scales it back up and the new one down, so reverting a bad image takes as
long as one rolling update and needs no registry access and no pipeline. The limit is
`revisionHistoryLimit` (ten by default), and it is worth keeping rather than trimming to save a
handful of objects.

**A stuck rollout reports itself if you let it.** `progressDeadlineSeconds` (ten minutes by
default) makes the controller set `Progressing=False` with reason
`ProgressDeadlineExceeded` when no progress has been made, which is what CI should wait on:
`kubectl rollout status --timeout` returns non-zero and the pipeline fails instead of declaring
success over a broken deploy. Without a readiness probe, new Pods are Ready the moment they
start, so the rollout completes regardless of whether the application works -- which is the
single most common reason a "successful" deploy takes a service down.

**What a Deployment is not for:** anything needing stable names, stable storage or ordered
startup, which is a StatefulSet; anything needing one Pod per node, which is a DaemonSet; and
anything that should run to completion, which is a Job.
