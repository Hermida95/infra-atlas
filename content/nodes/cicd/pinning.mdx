A pipeline runs other people's code next to your repository and your cloud credentials. An action referenced by a version tag resolves to whatever commit that tag points at today, and tags are mutable: the maintainer can move one, and so can whoever takes over the account.

Pinning to a full commit SHA freezes the exact tree that runs, and the version goes in a trailing comment so the line is still readable. It is the cheapest supply-chain control available in CI, and the one most pipelines skip.
