A software bill of materials lists every OS package and library baked into an artifact, with versions. Producing one is cheap, because the builder already knows: it installed them.

Its value shows up months later. With an SBOM attached to every image, "which of our images ship this library" is a query. Without one, it is an archaeology project across Dockerfiles, lockfiles and base images that have since moved.
