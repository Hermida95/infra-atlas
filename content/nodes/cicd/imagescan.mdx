Dependency scanning covers what you declared. An image also contains a base operating system, its package manager and whatever that brings in, and those are where a long-lived image rots: the code never changed, but the CVE count climbs every week.

Fail the build on high severity findings that have a fix available, and keep an explicit ignore file for the ones you have assessed and accepted. Both halves matter: without the first the scan is decorative, without the second it blocks on things nobody can fix.
