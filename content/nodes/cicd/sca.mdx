Software composition analysis reads your lockfile and compares it with vulnerability databases. It is the highest-yield security check in a pipeline, because most of the lines you deploy were written by somebody else and the problems in them are already public.

Run it against the locked set the artifact actually installs, not the loose ranges in your manifest, and pair it with something that opens the upgrade pull request for you. A report nobody acts on is not a control.
