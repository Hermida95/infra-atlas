Static application security testing builds a model of the code and queries it: user input reaching a shell command, a template rendered without escaping, a secret compared without a constant-time function. No execution, so it runs on every pull request.

It trades false positives for coverage, and the way to keep it useful is to treat its findings as review comments rather than as a gate that everyone learns to click through.
