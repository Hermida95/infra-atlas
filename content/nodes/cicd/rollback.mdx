A rollback is a deploy of the previous artifact. It only takes minutes if that artifact still exists, is still signed and the deploy path does not have to build anything, which is exactly why delivery promotes digests instead of rebuilding.

What does not roll back is state: a migration that dropped a column, a message already consumed from a queue, a file written in a new format. Those are what turn a two-minute rollback into an incident, and the reason the risky part of a release is rarely the code.
