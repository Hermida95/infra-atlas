In a push model, CI holds credentials for the cluster and runs the deploy. In GitOps an agent inside the cluster — Argo CD, Flux — watches a repository and continuously reconciles what is running with what is declared there.

Two things follow. Cluster credentials never leave the cluster, so a compromised pipeline cannot deploy. And drift becomes visible: anything changed by hand is reverted on the next reconcile, or flagged, instead of quietly surviving until the next release.
