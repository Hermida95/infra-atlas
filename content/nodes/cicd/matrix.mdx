A matrix expands one job definition into one run per combination: two Python versions, two operating systems, each language a scanner has to analyse. They run in parallel, so the wall-clock cost stays close to one job, and each combination reports separately.

The thing to watch is the combinatorics. Three dimensions with three values each is twenty-seven runners on every push. Most matrices want the short list of combinations you actually support, not the full product.
