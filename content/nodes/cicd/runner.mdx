A runner is a virtual machine or a container that exists for the length of one job. GitHub hosts them by default; you host your own when a job needs private network access, a GPU or a bigger disk.

Making it disposable is what buys reproducibility: a build that only works on a long-lived machine is a build nobody else can reproduce. The cost is that caches and credentials have to be handed over explicitly, which is also why a self-hosted runner on a public repository is a security decision rather than a performance one.
