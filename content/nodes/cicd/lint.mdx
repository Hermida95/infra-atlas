A linter reads the code without executing it and flags what it knows is wrong or inconsistent: an unused import, a mutable default argument, a branch that can never run. A formatter removes the question of style altogether by rewriting the file.

In a pipeline they go first, because they are the cheapest signal available. Failing in twenty seconds on a typo beats failing on the same typo eight minutes later, after the test job has installed every dependency.
