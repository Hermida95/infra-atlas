Continuous integration means every commit is built and verified on a shared machine, not only on the laptop that wrote it. The pipeline is where that happens, and its only product is an artifact that the delivery side can deploy.

Two properties make it worth trusting. It starts from a clean checkout every time, so nothing left over on somebody's machine can make it pass. And it is the same pipeline for every branch, so the main branch has no privileges the pull request did not already exercise.
