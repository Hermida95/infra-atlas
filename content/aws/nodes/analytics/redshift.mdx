Redshift is a columnar, massively parallel data warehouse. Data is distributed across node
slices, stored by column and compressed, so an aggregation over billions of rows reads only the
columns it needs. That is why it is fast at analytics and poor at the single-row lookups an
operational database does well.

Two decisions shape performance and they are made when the table is created. The **distribution
style** controls how rows are spread across nodes: `KEY` co-locates rows that join on the same
value (so the join happens without moving data), `ALL` replicates a small dimension table to
every node, `EVEN` round-robins, and `AUTO` lets Redshift choose. Getting a large join's
distribution key right is often the difference between seconds and minutes. The **sort key**
controls the physical order, so range-restricted scans skip blocks entirely -- usually the
timestamp column everything filters on.

**Redshift Serverless** removes the cluster: capacity in RPUs that scales with the workload and
charges when queries run, which suits spiky or intermittent analytics and is now the easiest
starting point. Provisioned clusters remain cheaper for sustained, predictable load, with
**RA3** nodes separating compute from **managed storage** so you scale them independently and
pay for the data once.

The features worth naming: **Spectrum** queries data still in S3 through the Glue catalogue, so
cold history stays in the lake and hot data in the warehouse, joined in one query. **Concurrency
scaling** adds transient clusters during bursts. **Materialised views** with automatic refresh
and rewriting speed up repeated aggregations. **Data sharing** gives another cluster or account
live read access with no copying. And **zero-ETL integrations** replicate from Aurora and RDS
continuously, which removes a whole pipeline for operational reporting.

Against Athena: Redshift when the warehouse is queried continuously by many people and the
modelling pays off; Athena when queries are occasional, over a lake, and nothing should be
running between them.
