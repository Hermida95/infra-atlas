EventBridge is the serverless event bus. Producers put events on it; **rules** match on the
event's content and send it to targets. Neither side knows about the other, which is the
property that makes event-driven architectures loosely coupled in practice rather than just on a
diagram.

The **default bus** already receives events from most AWS services, which is more useful than it
sounds: an EC2 instance state change, an ECS task stopping, a CodePipeline stage failing, a
Health event, a GuardDuty finding, an S3 object created, or **any CloudTrail API call** can
trigger something without polling. That last one is the general-purpose hook -- "when anyone
calls `DeleteBucket`, notify" is a rule, not a service.

**Event patterns** match structurally, not with a query language: fields you name must match,
fields you omit are ignored. Beyond equality there is prefix matching, numeric comparison,
`exists`, `anything-but` and IP matching. Patterns are the routing logic, and keeping them in
the rule rather than in a function is the difference between a bus and a dispatcher you wrote.

Three features that solve real problems. **Archive and replay**: keep matching events and replay
them later -- into a consumer you just wrote, or over a window where a bug dropped them.
**Schema registry** with code bindings, so consumers are typed against the event shape rather
than against a dictionary. **API destinations**, which let a rule call an external HTTPS API
with managed authentication, retries and rate limiting -- the integration you would otherwise
write a Lambda for.

**EventBridge Scheduler** deserves separate mention: millions of one-off or recurring schedules
with time-zone support, flexible time windows and a target of almost anything. It replaced both
cron on a server and the older CloudWatch Events scheduled rules, and "run this at 09:00 in the
customer's local time" is a configuration rather than a design.

**Pipes** is the fourth piece: a point-to-point connection from a source (SQS, DynamoDB Streams,
Kinesis, MSK) through optional filtering and enrichment to a target, which removes the glue
Lambda that existed only to forward.
